순환마루

이미지 인식 기반 대형 폐기물 분류 및 처리 지원 키오스크 웹 서비스

프로젝트 개요

순환마루는 사용자가 대형 폐기물 이미지를 업로드하면 AI 모델을 통해 품목을 인식하고, 분류 결과를 기반으로 처리 절차와 비용 정보를 제공하는 키오스크 형태의 웹 서비스입니다.

역할 및 기여도

  • 팀 프로젝트에서 프론트엔드, 백엔드, 배포 전담
  • Next.js 기반 키오스크 · 모바일 업로드 UI 구현
  • Spring Boot 기반 대형 폐기물 처리 API 서버 설계
  • FastAPI(YOLOv8) AI 서버 연동 및 추론 결과 처리
  • 이미지 업로드 → AI 추론 → 결과 반환 전체 흐름 설계
  • 세션 기반 상태 관리 및 결제/처리 로직 구현
  • Vercel(프론트), Render(Spring), Hugging Face Spaces(AI) 배포 환경 구축

핵심 기능

  • 모바일/키오스크 이미지 업로드
  • Base64 변환 후 서버 전송
  • AI 서버(YOLOv8) 연동 객체 탐지
  • 대형 폐기물 품목 자동 분류
  • 처리 비용 조회 및 결제 연동

기술 스택

  • Frontend: Next.js · TypeScript
  • Backend: Java · Spring Boot
  • AI Server: Python · FastAPI · YOLOv8
  • Image Processing: Base64 Encoding
  • Deployment: Vercel · Render · Hugging Face Spaces

프로젝트 인사이트

이 프로젝트를 통해 AI 모델 자체보다, AI 서버를 실제 서비스 흐름에 안정적으로 연결하는 백엔드 설계의 중요성을 체감했습니다. 특히 이미지 업로드 방식(Base64), 서버 간 통신, 추론 결과 가공 및 예외 처리 경험을 통해 실서비스 관점의 AI 연동 경험을 쌓을 수 있었습니다.

서비스 바로가기

MoodyMovie

사용자 대화를 기반으로 감정을 분석하고, 감정에 어울리는 영화를 추천하는 풀스택 웹 서비스

프로젝트 개요

MoodyMovie는 사용자의 대화 내용을 분석해 대표 감정과 세부 감정을 추론하고, 해당 감정에 적합한 영화를 추천하는 감정 기반 영화 추천 서비스입니다. 챗봇 인터페이스를 통해 자연스러운 사용자 경험을 제공하는 것을 목표로 했습니다.

역할 및 기여도

  • 팀 프로젝트에서 백엔드, AI, 배포 전담
  • Spring Boot 기반 API 서버 설계 및 구현
  • FastAPI 기반 감정 분석 AI 서버 개발
  • TF-IDF + ExtraTreesClassifier를 활용한 감정 분류 모델 학습
  • TMDB API 연동 및 감정 기반 영화 추천 로직 설계
  • 세션 기반 대화 상태 관리 및 챗봇 흐름 제어
  • Vercel · Render · Hugging Face Spaces 배포 환경 구성

기술 스택

  • Backend: Java · Spring Boot
  • AI Server: Python · FastAPI · scikit-learn
  • ML: TF-IDF · ExtraTreesClassifier(세부 감정 추론)
  • LLM: OpenAI GPT API (대화 요약 · 대표 감정 추론)
  • External API: TMDB API
  • Deployment: Vercel · Render · Hugging Face Spaces

프로젝트 인사이트

이 프로젝트를 통해 AI 모델과 백엔드 서버를 분리한 구조에서 서비스 간 데이터 흐름과 역할 분리의 중요성을 체감했습니다. 특히 FastAPI 기반 AI 서버와 Spring Boot 백엔드 간의 연동을 직접 설계하며 API 명세, 예외 처리, 상태 관리의 중요성을 실무적으로 경험할 수 있었습니다.

또한 모델 학습부터 추론, 배포까지의 전 과정을 직접 구성하면서 AI 기능이 실제 웹 서비스로 연결되는 전체 사이클을 이해하게 되었습니다.
